القيم الافتراضية للقالب في ملفه `theme.toml`. ولتغيير إحداها، اضبط المفتاح نفسه تحت `[extra]` في ملف `config.toml` عندك. تُدمج الجداول مفتاحًا مفتاحًا، فلا تكتب إلا ما يختلف؛ أما القائمة فتحلّ محل قائمة القالب كلها.

## الترويسة

تعرض الترويسة عنوان موقعك (مع شعار، إن ضبطت واحدًا)، وقائمتك، ورابط اللغة، وزر المظهر. وتحت نقطة التوقف المتوسطة تنطوي القائمة خلف زر.

```toml
[extra.header]
logo = "logo.svg"      # مسار في static/، يظهر قبل العنوان
sticky = true          # إبقاؤها في الأعلى عند تمرير الصفحة
theme_toggle = true    # زر المظهر: النظام، فاتح، داكن
language_link = true   # الصفحة نفسها في كل لغة أخرى

[[extra.menu.ar]]
name = "المدونة"
url = "@/blog/_index.md"   # محتوى، بهذه اللغة

[[extra.menu.ar]]
name = "الوسوم"
url = "/ar/tags/"          # أو مسار، أو عنوان ويب
```

ويمكن لإجراء واحد أن يبقى في الشريط عند كل عرض، على هيئة زر أساسي صغير:

```toml
[extra.header.action.ar]
name = "اشترك"
url = "@/subscribe.md"
```

## الصفحة الرئيسية

الصفحة الرئيسية هي ملف `content/_index.md` عندك. تأتي واجهتها من `[extra.hero]` في البيانات الأمامية لذلك الملف، ويلي محتواها الواجهة.

```toml
+++
title = "موقعي"

[extra.hero]
eyebrow = "كلمات اختيارية فوق العنوان"
title = "جملة واحدة تقول ما هذا."
lede = "جملة أو اثنتان لقوله كاملًا."
caption = "ما البلاطة الفيروزية في الزخرفة."
actions = [
  { name = "ابدأ من هنا", url = "@/docs/_index.md" },
  { name = "اقرأ المدونة", url = "@/blog/_index.md" },
]
+++
```

الإجراء الأول هو الزر الأساسي؛ والبقية روابط نصية بسهم. ويضع `links` روابط بأيقونات تحتها: `github`، أو `feed` (الخلاصة بلغة الصفحة، دون `url`)، أو أي أيقونة من أيقونات نظام التصميم.

```toml
links = [
  { name = "GitHub", url = "https://github.com/me/site", icon = "github" },
  { name = "خلاصة Atom", icon = "feed" },
]
```

يحلّ الشعار أو الصورة الشخصية محل البلاطة الفيروزية المحورية في الزخرفة (وفي الهاتف، يقع فوق العنوان):

```toml
[extra.hero]
image = "logo.svg"           # في static/، أو عنوان ويب؛ ويغيّر Zola مقاس الصور
image_alt = ""               # فارغ لشعار يسمّيه العنوان؛ ووصف للصورة
image_style = "logo"         # "logo" (كما هو، الافتراضي) أو "portrait" (مقصوص في دائرة)
# initials = "LH"            # دون صورة: أحرف أولى في دائرة، كعنصر نائب
                             # (وتعرض الصورة الشخصية دونهما صورة مجهولة)
# tint = "teal"              # ألوان العنصر النائب: teal أو blue أو green أو yellow أو orange
                             # أو pink أو purple أو cyan؛ ودونها رماديات محايدة
```

تقع الصورة الشخصية في هالة: حلقة بلون خلفية الصفحة وبخط رفيع، تُبعد الزخرفة من حولها (ليس في نظام التصميم ظلال). ويُرسم العنصر النائب في الصفحة بألوان القالب، فيتبع زر المظهر. ولتغيير أي من ذلك، اضبط هذه في ورقة أنماطك (`extra.stylesheets`):

```css
.zt-hero {
  --zt-hero-halo: 0.875rem;                          /* عرض الحلقة؛ 0 لإلغائها */
  --zt-avatar-ground: var(--al-color-surface-sunk);  /* دائرة العنصر النائب */
  --zt-avatar-figure: var(--al-color-line-strong);   /* شكل العنصر النائب */
}
```

وتحت الواجهة، أحدث صفحات قسم واحد:

```toml
[extra.home]
section = "blog/_index.md"   # "" (الافتراضي) لعدم عرض شيء
count = 5
pattern = true               # رسم الزخرفة عبر الواجهة
animate = true               # السماح لها برسم نفسها، مرة واحدة
```

## الصفحات

| المفتاح | الافتراضي | وظيفته |
|---|---|---|
| `extra.page.toc_min_headings` | 4 | إظهار «في هذه الصفحة» حين يكون في الصفحة هذا العدد من عناوين `h2`؛ و0 يوقفها |
| `extra.page.reading_time` | true | دقائق القراءة، بجانب التاريخ |
| `extra.page.page_nav` | true | روابط إلى الصفحتين السابقة واللاحقة، في الأسفل |
| `extra.page.back_to_top_after` | 0.5 | إظهار «العودة إلى الأعلى» بعد أن تُمرَّر الصفحة هذا العدد من الشاشات |

يمكن للصفحة إظهار فهرسها أو إخفاؤه بواسطة `toc = true` أو `toc = false` تحت `[extra]` في بياناتها الأمامية، وضبط صورة مشاركة بواسطة `image = "cover.png"`، مع `image_alt` لما تعرضه.

## التذييل

```toml
[[extra.footer.links.ar]]
name = "الخصوصية"
url = "@/privacy.md"

[[extra.footer.links.ar]]
name = "الشيفرة المصدرية على GitHub"   # مع أيقونة، الرابط هو الأيقونة، وهذا اسمه
url = "https://github.com/me/site"
icon = "github"

[extra.footer.text]
ar = "كُتب في لندن."

# بدلًا من «© %year %name.» في القالب؛ ويُحتفظ بوسوم HTML.
[extra.footer.copyright]
ar = 'صُنع بـ ♥ على يد <a href="https://example.com">أنا</a> | © %year'

[extra.footer]
lockup = false     # اسم الموقع (وشعاره) في التذييل أيضًا
credit = false     # «بُني باستخدام Zola ونظام التصميم آرابيسك»
feed_link = true   # أيقونة تربط بخلاصة Atom، بعد الروابط
```

## المشاركة والبحث

تصف كل صفحة نفسها للمواقع والتطبيقات التي تعرض معاينات الروابط: Open Graph (Facebook وLinkedIn وSlack وDiscord وMastodon ومعظم غيرها) وبطاقات X. وتصف نفسها لمحركات البحث أيضًا، ببيانات schema.org: الموقع في الصفحة الرئيسية، ومقالة مدونة لكل صفحة مؤرّخة، وصفحة ويب لما سواها. وإن لم تضبط شيئًا، تستخدم الوسوم عنوان كل صفحة ووصفها وتاريخها ووسومها وكتّابها وصورتها، ثم ما للموقع منها. اضبط فقط ما تريد إضافته:

```toml
[extra.social]
image = "social.png"                     # للصفحات التي ليس لها صورة؛ والأفضل 1200×630
image_alt = "اسم الموقع على الزخرفة"
twitter_site = "@site"                   # حساب الموقع على X
twitter_creator = "@you"                 # حساب الكاتب
fediverse_creator = "@you@example.social"  # ينسب إليه Mastodon الروابط المشارَكة
publisher_type = "Person"                # أو "Organization"
same_as = ["https://github.com/you"]     # حساباتك في أماكن أخرى
```

يوقف `enabled = false` كل هذه الوسوم، ويوقف `schema_org = false` بيانات schema.org وحدها.

## كل ما عدا ذلك

| المفتاح | وظيفته |
|---|---|
| `extra.search.page` | صفحة البحث (`"@/search.md"`): تضيف زر بحث إلى الترويسة |
| `extra.favicon` | أيقونتك أنت، في static/؛ والافتراضية نجمة القالب |
| `extra.author` | من يسمّيه سطر حقوق النشر؛ والافتراضي `author`، ثم العنوان |
| `extra.stylesheets` | ملفات CSS الخاصة بك، في static/، وتُحمَّل بعد ملفات القالب |
| `extra.rtl_languages` | اللغات التي تُكتب من اليمين إلى اليسار |
| `extra.language_names` | كل لغة مسمّاة بنفسها: اسم رابط اللغة |
| `extra.language_glyphs` | حرف كل لغة، يظهر في مفتاح بوصفه رابط اللغة (`ar = "ع"`، `en = "En"`) |
| `extra.i18n.<lang>` | الكلمات التي يكتبها القالب، لكل لغة |
