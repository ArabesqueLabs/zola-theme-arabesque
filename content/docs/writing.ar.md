يقرأ القالب البيانات الأمامية (front matter) الخاصة بـ Zola، وقليلًا من بياناته هو تحت `[extra]`.

## الأقسام

تُسرد صفحات القسم بإحدى طريقتين. فإن رُتّبت حسب التاريخ، فكل منها مقالة: تاريخها ووقت قراءتها، ثم عنوانها، ثم وصفها أو ملخصها. وإن رُتّبت بأي طريقة أخرى (حسب الوزن أو العنوان)، فهي قائمة روابط، كما في هذا الدليل.

```toml
+++
title = "المدونة"
description = "يظهر تحت العنوان."
sort_by = "date"
paginate_by = 10
+++
```

يذكر القسم المقسّم إلى صفحات ما يعرضه من المجموع («11 إلى 20 من 24») فوق القائمة، وصفحاته تحتها: «السابق» و«التالي» بالكلمات، وسبعة أرقام على الأكثر.

## الصفحات

```toml
+++
title = "عنوان الصفحة"
description = "المقدمة تحت العنوان؛ والملخص في القوائم ولمحركات البحث."
date = 2026-10-20
updated = 2026-10-24
draft = true          # تظهر بشارة «مسودة» ما دمت تشغّل الموقع مع --drafts
authors = ["لينا حداد"]

[taxonomies]
tags = ["تصميم", "Zola"]

[extra]
toc = true            # يتجاوز extra.page.toc_min_headings
image = "cover.png"   # صورة المشاركة، بجانب الصفحة
image_alt = "ما تعرضه الصورة"
+++
```

تعرض الصفحة التي قسمها مرتّب الصفحتين السابقة واللاحقة في أسفلها: «الأحدث» و«الأقدم» للتواريخ، و«السابق» و«التالي» لغيرها.

## قوالب أخرى

قالبان يتجاوزان قوالب Zola المعتادة. أعطِ الصفحة أحدهما بواسطة `template`:

- **`archive.html`**: كل صفحات قسم ما، حسب السنة. اضبط `section = "blog/_index.md"` تحت `[extra]`؛ وإلا فقسم الصفحة الرئيسية.
- **`search.html`**: بحث في المتصفح، ضمن فهرس الموقع بلغة الصفحة. يحتاج إلى `build_search_index = true` و`[search] index_format = "fuse_json"` لكل لغة، وهذا يفهرس العربية والإنجليزية معًا.

## المشاريع {#projects}

يعرض قسم المشاريع صفحاته في بطاقات: صورة كل منها، وعنوانها، ووصفها، وسنتها، وروابط إلى موقعها وشيفرتها المصدرية. وتليها أقسامه الفرعية، كلٌّ تحت عنوانه، كما تعرض صفحة [المشاريع](@/projects/_index.ar.md) تجاربها. أعطِ القسم قالبين، واحدًا له وواحدًا لصفحاته:

```toml
+++
title = "المشاريع"
sort_by = "weight"
template = "projects.html"
page_template = "project.html"
+++
```

كل مشروع صفحة، ولها هذه المفاتيح تحت `[extra]`، وكلها اختيارية:

```toml
+++
title = "فانوس"
weight = 10
description = "جملة واحدة: على البطاقة، وكمقدمة في صفحته."

[extra]
image = "cover.jpg"   # بجانب الصفحة (حزمة صفحة)، أو في static/ ("/img/x.png")، أو عنوان ويب
image_alt = ""        # في صفحة المشروع نفسها؛ أما على البطاقة فالصورة للزينة
year = "2025"
website = "https://example.com"
source = "https://github.com/me/lantern"   # يحصل عنوان GitHub على شعار GitHub
+++
```

يعرض المشروع الذي لا صورة له أول حرف من عنوانه على الزخرفة الهادئة. وفي صفحته، تقع السنة والروابط تحت العنوان، والصورة تحتها؛ ثم يأتي محتوى الصفحة، كما في أي صفحة. وكلمات الروابط هي `project_website` و`project_source` في `[extra.i18n.<lang>]`.

## الشيفرة

تصبح كتل الشيفرة كتلة الشيفرة في النظام، مع زر نسخ ولغتها في الشريط. علّم الأسطر المهمة بواسطة `hl_lines`:

```css,hl_lines=3
.al-code__pre {
  font-family: var(--al-font-mono);
  direction: ltr;
}
```

الشيفرة دائمًا من اليسار إلى اليمين، حتى في الصفحة العربية.
